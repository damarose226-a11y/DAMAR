# Dama Rose — متجر الحلويات

مشروع مستقل بالكامل عن أي مشروع آخر، ومجهز للعمل بقاعدة PostgreSQL وحسابات جديدة خاصة بـ Dama Rose.

## المزايا الحالية
- واجهة عربية افتراضيًا مع تحويل إلى الإنجليزية.
- الأقسام: بقلاوات، قشاطي، كنافة، نواشف.
- قسم «ما نختاره لك» قابل للتحديث يوميًا.
- منتج بصورة واحدة، وأحجام وأسعار متعددة لكل منتج.
- سلة شراء بدون تسجيل دخول.
- إنهاء الطلب عبر واتساب.
- صفحة عروض.
- من نحن وتواصل معنا.
- لوحة إدارة على /admin.
- مدير رئيسي ومدراء بصلاحيات يحددها المدير الرئيسي.
- إضافة/تعديل/حذف المنتجات والعروض.
- تعديل واتساب والعنوان من لوحة الإدارة.
- فحص صحة على /api/health.

## متغيرات البيئة
انسخ القيم الموجودة في `.env.example` إلى إعدادات الاستضافة:

- `DATABASE_URL`: رابط قاعدة PostgreSQL الخاصة بـ Dama Rose.
- `OWNER_USERNAME`: اسم مستخدم المدير الرئيسي.
- `OWNER_PASSWORD`: كلمة مرور قوية للمدير الرئيسي.
- `SESSION_SECRET`: قيمة عشوائية طويلة لحماية الجلسات.
- `PORT`: اختياري، الافتراضي 3000.

لا ترفع ملف `.env` الحقيقي إلى GitHub.

## التشغيل محليًا
```bash
npm install
npm start
```

ثم افتح:
- الموقع: http://localhost:3000
- الإدارة: http://localhost:3000/admin
- الصحة: http://localhost:3000/api/health

## النشر
المشروع يحتوي `render.yaml` و `Procfile`، لذلك يمكن ربط المستودع بحساب Render جديد وإضافة متغيرات البيئة السابقة.

## قاعدة البيانات
الجداول تُنشأ تلقائيًا عند أول تشغيل. المدير الرئيسي يُنشأ تلقائيًا من متغيرات البيئة عند عدم وجود مدير رئيسي في القاعدة.
